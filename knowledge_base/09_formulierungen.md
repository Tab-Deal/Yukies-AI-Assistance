# Erlaubte und verbotene Formulierungen
Freigegeben von Silvia Ragucci (09.11.2026). Höchste Priorität vor allen anderen Quellen, auch vor Produkttexten auf der Website.

## Verboten → stattdessen
- ✗ löst Krämpfe und Blähungen effektiv; hilft bei Koliken / Drei-Monats-Koliken → ✓ eine sanfte Bauchmassage, die deinem Baby guttut
- ✗ wissenschaftlich erwiesen; tiefenentspannend (Kakaoduft) → ✓ weglassen; „duftet dezent nach Kakao“
- ✗ hält die Haut elastisch → ✓ unterstützt die natürliche Elastizität der Haut
- ✗ verhindert Dehnungs-/Schwangerschaftsstreifen → ✓ pflegt die Haut, während sie sich dehnt
- ✗ unterstützt den Abfluss der Lymphflüssigkeit → ✓ kosmetische Lymphdrainage
- ✗ tut der Verdauung gut → ✓ weglassen
- ✗ bietet sanftesten / wirksamen Schutz → ✓ pflegt zarte Haut besonders sanft
- ✗ vollkommen sicher; völlig bedenkenlos; absolut → ✓ weglassen
- ✗ tierversuchsfrei (als besonderer Vorteil) → ✓ vegan
- ✗ Neurodermitis → ✓ nicht verwenden; bei Hauterkrankungen auf Ärztin/Arzt verweisen

## Erlaubt
- vegan, dermatologisch getestet, reizfrei, sanft zur Haut, frisch gefertigt, Manufaktur-Qualität, keine Massenware
- hypoallergen: für alle Produkte außer Sugar Scrub
- COSMOS NATURAL / COSMOS ORGANIC, zertifiziert durch Ecocert Greenlife
- frei von Parfum und ätherischen Ölen (alle Produkte außer Sugar Scrub)
- Body Butter: „100 % Bio“ (100 % Bio-Inhaltsstoffe), „von Natur aus reich an Vitamin E“, „hypoallergen“
- Tummy Stick: „100 % Bio-Kakaobutter“

## Allergien und Gesundheit
Keine Allergie- oder Nussaussagen. Auf Nachfrage die Inhaltsstoffe (INCI) nennen und bei Allergien, Hautreaktionen oder Hauterkrankungen eine Ärztin/einen Arzt bzw. die Hebamme empfehlen und an das Team übergeben.
